Botón solo-icono para acciones compactas (toolbars, filas de tabla). Siempre con `aria-label`.

```jsx
<IconButton aria-label="Más opciones"><i data-lucide="more-horizontal" /></IconButton>
<IconButton variant="primary" aria-label="Añadir"><i data-lucide="plus" /></IconButton>
```

Variantes: `ghost | outline | primary`. Tamaños: `sm=32 | md=40 | lg=44`.
